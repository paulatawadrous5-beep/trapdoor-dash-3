# Trapdoor Dash 3

30 devilish levels across 3 zones — Green Hills 🌿, Devil's Factory 🏭, Hell's Gate 🔥.

## Features

- **World map** with 3 zones × 10 levels, locked/unlocked progression (saved locally)
- **Stars** — 3 per level, earn points
- **Points & hints** — spend 150 pts on a hint when stuck
- **Chasers, saws, fake doors, pop-up & falling spikes** — Level Devil style
- **Sound effects** — jump, footsteps, stars, death, win (no background music)
- **Gloria** — cute new playable character 💚
- **Paul devil animation** after each zone
- **PWA** — installable on mobile (Add to Home Screen), works offline
